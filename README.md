# FT — Fedor Testing

A simple two-page static site styled after a broadsheet financial newspaper. Built for testing Amplitude Analytics and Web Experiment.

- `index.html` — home page
- `article.html` — article page
- `styles.css` — shared styles
- `app.js` — shared script (Amplitude hooks go here)

Open `index.html` directly in a browser, or serve with `python3 -m http.server`.
